\# Requisitos



Java 21.



Maven >= 3.8.5 



Testado com Windows 11 e Docker 29.2.1



\## Instalação



Na raiz do projeto



```bash

docker build -t testejoao:1.0 .

```



\## Usage



```python

import foobar



\# returns 'words'

foobar.pluralize('word')



\# returns 'geese'

foobar.pluralize('goose')



\# returns 'phenomenon'

foobar.singularize('phenomena')

```
